PARA REVISAR EN TU COMPUTADORA
Extrae el ZIP y abre index.html en tu navegador. Mantén todos los archivos
y la carpeta assets juntos. No necesita instalación ni compilación.

PARA PUBLICAR EN GITHUB PAGES
1. Crea un repositorio NUEVO, por ejemplo flores-sector-privado.
   No reemplaces los archivos del repositorio de la web para el Estado.
2. Extrae el ZIP. Sube su CONTENIDO al nivel principal del repositorio:
   index.html, las demás páginas, styles.css, script.js y la carpeta assets.
   No subas solamente el ZIP ni dejes index.html dentro de otra carpeta.
3. Guarda los archivos en la rama principal del repositorio.
4. Activa GitHub Pages para publicar desde la rama principal y su carpeta raíz.
5. Abre el enlace que GitHub indique cuando termine la publicación.
