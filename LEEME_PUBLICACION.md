# FLORES | Ingeniería y Construcción — Sector privado
**Versión corporativa con certificados ISO en español · 21 de noviembre de 2026**

## Publicar en GitHub Pages
1. Descomprime este ZIP. **No subas el ZIP como un solo archivo al repositorio.**
2. Entra en https://github.com/migoreslavconstructionsac-lab/flores-sector-privado (rama `main`).
3. Elige **Add file → Upload files**.
4. Arrastra **todos los archivos de la raíz y la carpeta `assets`**, manteniendo la estructura. Si GitHub pregunta por reemplazar archivos existentes, confirma la actualización.
5. Selecciona **Commit changes**.
6. Cuando se complete la publicación, revisa https://migoreslavconstructionsac-lab.github.io/flores-sector-privado/ . Para evitar caché, utiliza `Ctrl + F5`.

En el ZIP, `index.html` es Inicio; `acabados.html`, `construccion.html`, `diseno.html` y `remodelaciones.html` son páginas de servicios; `proyectos.html` es la página de respaldo; `contacto.html` permite preparar una consulta para WhatsApp; `styles.css` y `script.js` contienen el diseño y la interacción; `perfil_empresarial_flores.pdf` es un perfil descargable; `assets/` contiene imágenes e isotipo.

- Ajustes de tarjetas, navegación y visualización adaptable a móviles.

## Importante antes de difundir la web a inmobiliarias
- **Portafolio real pendiente:** no se añadieron proyectos, conformidades, resultados, testimonios ni fotos de trabajo propio que no estén acreditados. Para completar este apartado, incorporar fichas y fotos reales con autorización de publicación.
- **Documentos de proveedor:** la web no declara tener certificados, seguros, personal técnico ni equipos cuya vigencia o disponibilidad no haya sido verificada.
- **Datos:** verificar que la razón social, el RUC, el teléfono, el email y la garantía sigan siendo correctos.
- **Formulario:** no envía datos a un servidor. Prepara un mensaje para WhatsApp que el visitante puede revisar y enviar. **No adjunta planos automáticamente.**
- **Difusión:** reemplazar las imágenes referenciales por fotografías reales autorizadas, cuando estén disponibles, para elevar la confianza comercial.
