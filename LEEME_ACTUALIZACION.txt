CÓMO ACTUALIZAR EL REPOSITORIO EXISTENTE
1. Extrae este ZIP en tu computadora.
2. Entra a https://github.com/migoreslavconstructionsac-lab/flores-sector-privado
3. En la rama main, usa Add file > Upload files.
4. Arrastra TODOS los archivos y la carpeta assets al repositorio.
5. Confirma la sustitución de los archivos existentes y haz Commit changes.
6. NO elimines el repositorio ni modifiques GitHub Pages; ya está activado.
7. Recarga https://migoreslavconstructionsac-lab.github.io/flores-sector-privado/ con Ctrl+F5.
Nota: el ZIP no se sube directamente; se suben los archivos extraídos.
